# Teste Estrutural (Caixa Branca)

## Objetivo Principal

Aplicar os conceitos de teste estrutural (caixa branca) para compreender o comportamento interno de um programa e avaliar a cobertura de código por meio da análise de nós, arestas e caminhos.

O foco é permitir que os estudantes desenvolvam a capacidade de visualizar o fluxo lógico, identificar caminhos executáveis e não executáveis e projetar casos de teste eficazes que garantam a verificação completa da lógica interna.

## Competências Desenvolvidas

- Analisar a estrutura interna de um programa.
- Construir o grafo de fluxo de controle (GFC).
- Identificar nós, arestas e caminhos executáveis.
- Aplicar critérios de cobertura estrutural (Todos-Nós, Todas-Arestas e Todos-Caminhos).
- Projetar casos de teste mínimos que satisfaçam cada critério.
- Utilizar ferramentas para visualizar e medir a cobertura de código.
